# ختم اسم المشتري على كتاب From Zero to Hero

في هذا المجلد سكربتان:

- `watermark_footer.py` (**الموصى به**): سطر صغير رمادي أسفل كل صفحة:
  `© Ali Alkhuzaee · alialkhuzaee.com — مرخّصة لـ: الاسم · البريد · رقم الطلب`
- `watermark_diagonal.py`: نص كبير مائل 45° بلون رمادي فاتح وشفافية 12% وسط كل صفحة:
  `مرخّصة لـ: الاسم - البريد`

في المستودع يقرأ السكربتان الخطوط من `store_service/orders/fonts`؛ عند نسخهما خارج المستودع ضع مجلد `fonts` بجانبهما. الخطوط هي خطا IBM Plex اللذان يكتبان العربية والروسية بشكل صحيح، ويجعلان النص المنسوخ من الختم صحيحاً.

> عند البيع عبر متجرك (store.alialkhuzaee.com) لن تحتاج هذين السكربتين: المتجر يختم كل نسخة تلقائياً لحظة التحميل. السكربتان للحالات اليدوية (نسخة هدية، مراجع، بيع مباشر).

## التثبيت (مرة واحدة فقط، على الماك)

1. افتح تطبيق **Terminal** (اضغط `Cmd + Space` واكتب Terminal ثم Enter).
2. تأكد أن بايثون موجود: اكتب `python3 --version` ثم Enter. إذا ظهر رقم مثل `Python 3.12.x` فهو موجود. إذا طلب الماك تثبيت "Command Line Tools" فوافق وانتظر حتى ينتهي.
3. ثبّت المكتبتين بهذا الأمر:

```
python3 -m pip install PyMuPDF fonttools
```

(على ويندوز اكتب `py -m pip install PyMuPDF fonttools`.)

## التشغيل (لكل مشترٍ)

1. ضع ملف الكتاب الأصلي (مثلاً `ZeroToHero_AR.pdf`) داخل هذا المجلد نفسه.
2. افتح `watermark_footer.py` بأي محرّر نصوص (TextEdit أو VS Code)، وغيّر الأسطر في قسم **الإعدادات** فقط:
   - `INPUT_PDF`: اسم ملف الكتاب الأصلي.
   - `OUTPUT_PDF`: اسم الملف الجديد للمشتري.
   - `BUYER_NAME` و `BUYER_EMAIL`: اسم المشتري وبريده.
   - `ORDER_REF`: رقم الطلب (أو اتركه `""`).
   - `BOOK_LANGUAGE`: `"ar"` أو `"en"` أو `"ru"` حسب لغة الكتاب.
   احفظ الملف.
3. في Terminal اكتب `cd ` (مع مسافة)، ثم اسحب هذا المجلد من Finder وأفلته داخل نافذة Terminal، ثم Enter.
4. شغّل السكربت:

```
python3 watermark_footer.py
```

5. ستظهر رسالة `Done: ... (106 pages)` ويظهر الملف الجديد في المجلد نفسه. افتحه وتأكد من السطر أسفل الصفحات، ثم أرسله للمشتري.

للنسخة المائلة: نفس الخطوات مع `watermark_diagonal.py`.

**مهم:** لا ترسل الملف الأصلي أبداً، أرسل فقط الملف الجديد المختوم.

## ماذا يضيف الختم؟

- السطر الظاهر (أسفل الصفحة أو مائل).
- نسخة مخفية من بيانات المشتري في خصائص الملف (File › Properties › Subject).
- نص الكتاب وخطوطه لا تتغيّر، والنسخ واللصق يبقى صحيحاً.

## بدون برمجة (للعلم)

- **Gumroad و Payhip** فيهما ميزة **PDF Stamping**: تفعّلها من إعدادات المنتج (في Payhip: خيار "PDF Stamping" في صفحة المنتج، وفي Gumroad: خيار "Stamp PDF with buyer's email" أو ما يشبهه حسب الواجهة الحالية). عندها تضع المنصة بريد المشتري على الصفحات تلقائياً. أنت لا تبيع عبرهما الآن، ومتجرك يفعل الشيء نفسه وأكثر (الاسم + البريد + رقم الطلب + صفحة الترخيص).
- **علامة ثابتة** في Canva أو Adobe Acrobat Pro (مثل `© alialkhuzaee.com — Do not distribute`): تذكير بحقوق النشر فقط، لا تكشف من سرّب النسخة.

لا توجد حماية تمنع السرقة 100%، لكن اسم المشتري وبريده على كل صفحة يردع أغلب الناس عن المشاركة، ويثبت مصدر أي نسخة مسرّبة.

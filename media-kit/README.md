# Media Kit maintenance

This remains part of the static personal website at `/media-kit/`. Production serves the repository root, not ignored local `dist/` preview files.

- Shared site design: `assets/site.css`, `assets/site.js`, `assets/translations.json`.
- Media Kit-specific EN/AR/RU copy: `media-kit/translations.json`.
- Verified platforms, selected videos, and source-dated metrics: `media-kit/data.json`.
- Static fallback pages: generated by `python scripts/build_site.py`.
- English standalone PDF: `python scripts/build_media_kit_pdf.py`.
- Original portraits, optimized derivatives and alpha masks: `assets/portraits/`; rebuild with `python scripts/prepare_portraits.py`.

UI languages are English, Arabic and Russian. Communication capabilities include Arabic, English, Russian and Ukrainian. These are separate concepts and do not establish audience demographics.

Metrics remain hidden until dated, sourced data is approved. Never guess follower counts, audience geography, sponsors or prices. Keep Snapchat unchanged unless Ali verifies a replacement.

Review `docs/redesign-review.md` for preview approval requirements, original production audit, preservation checks and the French URL migration limitation. Do not merge the redesign to main without explicit approval.
